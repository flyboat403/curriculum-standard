# 学习情境设计模板

本文件提供三种不同深度的学习情境设计模板。

## 核心格式规则（必须遵守）

**每个学习情境由三个表格组成：**

1. **（一）基本信息**：属性-内容对照表（单列表格）
2. **（二）内容设计**：学习内容、职教高考考点、职业技能证书、课程思政、教学环境与资源（合并为一个**表格**）
3. **（三）教学设计**：教学方法、组织形式、教学流程、学习成果、评价量规（合并为一个**表格**）
4. **（四）评价设计**：学习成果、评价量规

**禁止事项：**
- ❌ 不能将各部分拆分成多个独立表格（每个表格内各部分必须连续）
- ❌ 不能有独立的段落文本（如教学方法直接写为纯文本）

**必须事项：**
- ✅ 内容设计表格中，各部分开始用粗体标题行
- ✅ 教学设计表格中，教学方法、组织形式、教学流程、学习成果为两列（属性+内容）
- ✅ 评价量规在内容设计表格中是嵌套表格结构

## 模板一：岗课赛证考融合版（最完整）

适用于：职教高考科目、专业核心核心课程、课证融通课程

### 表格结构说明

**（一）基本信息**

```markdown
| 属性 | 内容 |
|------|------|
| 学习情境 | [N]名称 |
| 总学时 | [N] |
| 描述 | [工作场景描述] |
| 要求 | 1. [要求1]<br>2. [要求2]<br>... |
| 学习目标 | 1. [知识目标]<br>2. [能力目标]<br>3. [素质目标] |
```

**（二）内容设计**

```markdown
| 属性 |  |内容 |  |

| [内容1] | [任务1] | [N] | [能力描述] |

| [考点2] | 记忆/理解/应用 | 较易/中等/较难 | [N]% |

| **课程思政** |  |  |  |
| 思政载体 | 思政元素 | 思政方式 | 思政目标 |

| [载体2] | [元素2] | 案例教学/小组研讨/情境教学/项目实践 | 认同* |
| **教学环境与资源** |  |  |  |
| 教学环境 | 教学资源 | 教师能力 | 学生学习基础 |

```

**（三）教学设计**

```markdown
| 属性 | 内容 |
|--------------|--|
| **教学方法** |任务教学法、项目教学法、案例教学法|
| **组织形式** |分组协作完成项目任务，教师巡回指导|
| **教学流程** |1.课前：预习...<br>2.课中：教师讲解→演示操作→学生分组实践→成果展示→点评总结<br>3.课后：完成拓展练习，参与在线互评|
```

**（四）评价设计**

```markdown
| 属性 | 指标 |形式或比例|
|--------------|--|--|
| **学习成果** |||
|成果类型|成果名称|成果数量
|作品|1.成果1| [N]个 |
|服务|2.成果2| [N]项 |
|产品|3.成果3| [N]个 |
| **评价量规** |  |  |
| 评价项目 | 标准（比例） | 评价主体 |
| 学习态度 | 任务完成进度（15%）、团队协作（15%）、课堂表现（10%） | 学生自评、小组互评、教师评价 |
| 学习成果 | 质量（30%）、技术实现度（20%）、创意表现（10%） | 教师评价、企业专家评价 |
```

### 关键格式要点

1. **基本信息表格**：两列表格，属性列+内容列
2. **内容设计表格**：四列表格，各部分用粗体标题行分隔，列数保持一致
3. **教学设计表格**：两列结构，各部分用粗体标题行分隔，列数保持一致
4. **评价设计表格**：三列结构，各部分用粗体标题行分隔，列数保持一致

## 填写规范

| 字段 | 要求 | 示例 |
|------|------|------|
| 学习情境名称 | 序号+动词短语 | 1 发动机系统维护作业 |
| 描述 | 50-100字，场景+核心技能 | 在举升机工位，使用工具设备，完成发动机系统的清洁、检查、润滑作业。 |
| 要求 | 3-4条，以"能/掌握/应用/培养"开头 | 1.能完成发动机舱清洁检查<br>2.能更换机油和滤清器 |
| 学习目标 | 知识+能力+素质三类 | - 1.知识目标：掌握发动机维护知识 - 2.能力目标：能独立完成发动机维护<br>3.素质目标：培养精细化操作习惯 |
| 考点内容 | 职教高考具体考点 | 发动机舱检查、机油更换规范 |
| 考试要求层次 | 记忆/理解/应用/分析 | 应用 |
| 难易程度 | 较易/中等/较难 | 中等 |
| 分值比例 | 高考占比 | 10% |
